## 检查项

- [ ] **启动与首页**：冷启动后页面正常显示；首页内容可滚动，继续观看记录可打开。
- [ ] **浏览与栏目切换**：打开浏览页后可进入栏目和分类；同一栏目刷新时旧结果仍可见，加载完成后列表更新；切换栏目或筛选后不残留上一栏结果；继续下滑可追加内容且无重复项。
- [ ] **详情与播放**：从列表进入详情，作品信息及可用画质正常显示；选择画质后能启动系统播放器，关闭后返回详情页。
- [ ] **字幕**：搜索并下载简体或繁体字幕；返回后字幕自动关联当前作品；播放时字幕在画面下方显示且与进度匹配，详情页开关可控制显示。
- [ ] **线路验证（仅线路要求时）**：从设置打开“验证访问线路”，确认实际验证页可见；完成挑战并关闭后，首页和浏览页刷新，受保护栏目能正常加载，不显示错误的验证通过状态。
- [ ] **本地记录**：播放一段时间后退出播放器并重新进入该作品，继续播放位置正确；重启脚本后播放记录与进度仍在。

# Scripting 3.2.1 分阶段优化方案

这是开发实施方案，不是脚本版本更新日志。脚本版本保留 1.0.0。
直接在现有仓库推进，每阶段独立验证、提交和推送，不创建隔离 worktree。

## 保留的行为

- 中文 cn 路径、当前栏目与筛选，验证窗口只由设置页开启。
- 已实现的验证请求合并、准确路径检查、Cookie 复用和验证结果缓存。
- 原生播放器控件、原生关闭、当前横屏逻辑；不增加完成按钮或画面比例按钮。
- 单行字幕，字体 27 点、底部间距 25 点、白字黑色描边。
- 字幕存储在脚本的 subtitles 文件夹；下载文件数量不限，不自动淘汰。
- 不默认启用云同步、后台保活、Node/npm 或新的爬虫会话。

## 阶段与验收

当前进度：第一阶段代码与本地验收已完成（18 组 mjs 回归、7 组 TS 回归、47 个 TS/TSX 文件语法转换检查）；真实 iPhone 的耗时与恢复体验另行验收。
第二至第五阶段按顺序独立推进，不在第一阶段混入缓存迁移或播放器界面改动。

第二阶段：已实施播放状态回调、暂停/最小化保存、限量合并写入、结束/关闭清理；原生控件和字幕布局不变。19 组 mjs 与 7 组 TS 回归、48 个 TS/TSX 语法转换检查通过；手机原生行为待验收。

### 第一阶段：耗时诊断、恢复事件与主线程降负载

- 分开记录 Cookie 恢复、网页读取、Cookie 保存、列表/详情解析耗时。
- 同一次请求内，相同 HTML 快照只解析一次；快照变化必须重新解析。
- 用官方 Thread API 执行字幕解析、排序、索引及保存前文本整理；文件读写、设置和 UI 留在调用线程。
- 接入最小化/恢复事件，去重并释放监听；恢复不重建页面、不自动验证、不批量请求。
- 所有诊断限量且只保留固定标签、数字、布尔值，不保存原始 HTML、字幕、路径、搜索词、Cookie 或账号。

本地验收：实际生产模块回归、线程可用/不可用/失败、重复恢复、清理监听、请求取消和保密检查。
手机验收：脚本启动与恢复正常；保持原栏目/筛选；字幕仍按进度显示；设置验证流程没有新增窗口。
具体加速幅度须以手机测量为准，不以 Node 模拟耗时代替真实数据。

### 第二阶段：播放器状态管理与进度保存

- 使用 AVPlayer 已公开的播放状态变化回调；暂停、结束、最小化和退出时保存进度。
- 保留低频进度采样及字幕时间采样；不假设存在未公开的周期时间观察 API。
- 防止重复定时器、过期回调和连续写入；暂停/拖动后字幕及时更新。

验收：暂停、拖动、最小化恢复、续播、原生关闭；字幕样式与原生控制不改变。

### 第三阶段：SQLite 持久缓存与查询优化

- 查询真实执行路径，再添加必要索引、合并相关写入。
- 按域名、语言、栏目、页码、排序和筛选完整区分缓存。
- 成功内容可持久缓存；离线旧内容必须标明状态，不能把旧内容当作线路验证成功。
- 请求失败与验证页面不能覆盖有效内容；保留现有历史、收藏与播放进度。

验收：迁移可重复、域名隔离、断网/失败回退、手动刷新、记录完整性。

### 第四阶段：栏目读取与 DOM 提取试验

- 先在现有持久 WebView 中提取精简 DOM 数据，保留现有 HTML 解析回退。
- 验证完整路径与页面内容，覆盖目录、作品、分页及没有筛选的栏目。
- 不直接改用 WebScraper：官方未承诺它与现有 WebView 共享 Cookie，不能据此解决 Cloudflare。

验收：相同页面新旧结果一致、特殊厂商栏目有内容、验证页不误判、取消请求后不更新界面。

### 第五阶段：字幕下载与预览完善

- 优化下载内容验证与写入失败处理，确保详情页关联的是正在查看的视频。
- 增加按需文本预览；保留简中/繁中置顶及目前搜索列表布局。
- 避免重复解析和重复下载；搜索缓存限量不影响已下载字幕无限保留。

验收：搜索、下载、关联、预览、播放、损坏文件、同作品并发与旧文件兼容。

## 官方能力依据与边界

- [Thread](https://scriptingapp.github.io/zh/guide/Utilities/Thread)：纯计算可以后台执行；异步文件/网络/数据库 I/O 已由宿主调度；后台不能访问 UI。
- [Script 最小化与恢复](https://scriptingapp.github.io/zh/guide/Changelog/2.4.9/Script%20Minimization%20and%20Resume)：onResume 是存活实例的恢复/再触发，不是任意 iOS 前后台通知。
- [AVPlayer](https://scriptingapp.github.io/zh/guide/Changelog/3.1.0/AVPlayer)：按已公开状态回调实施，保留必要的时间采样。
- [WebScraper](https://scriptingapp.github.io/zh/guide/Utilities/WebScraper)：独立会话只能试验，不替换已验证的持久 WebView 链路。

这些是 3.2.1 中可利用的宿主能力，不意味着它们全部新增于 3.2.1，也不意味着升级本身解决 Cloudflare。

# MISSAV 4.0 对齐与文案规范

## 1. 对齐不是单一方向

4.0 根据语义分配对齐轴，不执行全局统一左对齐。

| 内容 | 对齐 | 原因 |
|---|---|---|
| 页面标题、区块标题、作品标题、元数据、说明 | 左对齐 | 形成稳定阅读起点，支持长文本与多行内容 |
| 封面缩略图、正文列、尾部 chevron | 整行垂直中线 | 保持媒体行视觉平衡，避免 accessory 顶部漂移 |
| 空状态、整页加载、无结果说明 | 水平居中 | 作为页面级状态焦点，不与内容列表阅读轴混淆 |
| 主按钮与次级按钮内部 | 居中 | 操作标签与图标构成单一控制语义 |
| 分页页码 | 居中 | 在上一页和下一页之间建立稳定中轴 |
| 计数与 chevron | 尾部对齐 | 作为 accessory，不压缩正文主轴 |
| 筛选与分类 | 内容自然宽度；选中图标与文字同轴 | 允许横向扫描，避免平均分配导致截断 |
| 详情双收藏 | 常规宽度并排居中；内容压力过高时应回退纵向 | 同级操作等权，但正文可读性优先 |

## 2. 几何规则

- 页面水平 inset：18pt。
- 页面底部内容余量：44pt。
- 大区块间距：28pt。
- 最小命中区：44×44pt。
- 主操作最小高度：52pt。
- 次级操作最小高度：48pt。
- 普通导航行最小高度：58pt。
- 媒体列表封面：112×63pt，圆角 10pt。
- 横向媒体封面：184×104pt，圆角 14pt。
- 媒体 Hero 圆角：18pt。
- 前导图标槽：28pt；尾部 accessory 槽：16pt。
- 多行文字必须同时设置容器 leading、Text frame leading 与 multiline leading。
- 正文优先于计数、按钮和 chevron；不得用固定尾宽长期压缩正文。

## 3. 颜色与表面

- 页面：`systemBackground`。
- 轻量输入与分类：`secondarySystemBackground` / `tertiarySystemFill`。
- 品牌强调：`systemPink`，仅用于主操作、选中、关键图标和必要状态。
- 错误：`systemRed`，同时配合错误图标和文字。
- 成功：可使用 `systemGreen`，同时配合状态图标和文字。
- 页面层级由系统语义背景、排版、留白、轻量填充和分隔线共同建立；动效仅用于操作与状态反馈。
- 分类入口不得依赖多种高饱和彩底建立 identity。

## 4. 正式文案原则

1. 使用准确、克制、可执行的句子。
2. 区分“浏览”“搜索”“播放”“继续观看”，不混用“发现”。
3. 搜索范围统一为“番号、女优或作品标题”。
4. 使用“本机收藏”“网站收藏”，明确数据归属。
5. 使用“浏览记录”“播放记录”，不简称为含混的“浏览”“播放”。
6. 数量单位使用“部作品”，不使用“个内容”。
7. 省略号仅用于真正持续中的状态；常规说明使用句号。
8. 错误文案说明当前结果和恢复动作，例如“当前显示已成功载入的内容”。
9. 已收藏状态优先使用肯定式文案“已加入本机收藏”，辅助功能再说明“轻点取消”。
10. 不使用“AI”“智能”等无法证明的营销措辞。

## 5. 标准术语

| 概念 | 标准文案 |
|---|---|
| Main browse tab | 浏览 |
| Search scope | 番号、女优或作品标题 |
| Local saved | 本机收藏 |
| Account saved | 网站收藏 |
| Playback history | 播放记录 |
| Detail visit history | 浏览记录 |
| Continue action | 继续观看 |
| Reload failed with stale data | 刷新失败，当前显示上次成功载入的内容。 |
| No playable source | 暂无可用播放源 |
| Local privacy | 仅保存在本机 / 不会上传 |
| Website ownership | 来自当前网站账号 / 将同步至当前网站账号 |

## 6. 真机压力检查

- 320–375pt 窄屏。
- 两行、三行和四行作品标题。
- 长番号、长日期、长制作方。
- 最大常用 Dynamic Type。
- VoiceOver 阅读顺序。
- 灰度、Increase Contrast、Reduce Transparency。
- 双收藏按钮是否出现压缩；如压缩应改为纵向布局，而不是缩小字体。
- 状态行尾部重试按钮是否压缩正文；如压缩应改为下方动作。
